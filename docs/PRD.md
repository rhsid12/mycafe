# 커피 주문 앱

## 1. 프로젝트 개요

### 1.1 프로젝트 명
커피 주문 앱

### 1.2 프로젝트 목적
사용자가 커피 메뉴를 주문하고, 관리자가 주문을 관리할 수 있는 간단한 풀스택 웹 앱

### 1.3 개발 범위
- 주문하기 화면(메뉴 선택 및 장바구니 기능)
- 관리자 화면(재고 관리 및 주문 상태 관리)
- 데이터를 생성/조회/수정/삭제할 수 있는 기능

## 2. 기술 스택
- 프런트 엔드: HTML, CSS, 리액트, 자바스크립트
- 백엔드: Node.js, Express
- 데이터베이스: PostgreSQL

## 3. 기본 사항
- 프런트엔드와 백엔드를 따로 개발
- 기본적인 웹 기술만 사용
- 학습 목적이므로 사용자 인증이나 결제 기능은 제외
- 메뉴는 커피 메뉴만 있음

## 4. 화면 요구사항

### 4.1 주문하기 화면
- 상단 헤더에 `COZY`, `주문하기`, `관리자` 노출
- 메뉴 카드 3종(아메리카노 ICE/HOT, 카페라떼) 표시
- 메뉴별 옵션 체크박스(샷 추가 +500원, 시럽 추가 +0원) 지원
- `담기` 클릭 시 장바구니에 옵션 포함 항목 추가
- 동일 메뉴+옵션 조합은 수량 증가 방식으로 합산
- 장바구니에 항목 목록, 항목별 금액, 총 금액, `주문하기` 버튼 표시

### 4.2 관리자 화면
- 상단 헤더에서 `관리자` 탭 활성화
- 대시보드 지표 표시: 총 주문 / 주문 접수 / 제조 중 / 제조 완료
- 재고 현황 카드(아메리카노 ICE/HOT, 카페라떼)와 `+`, `-` 버튼 제공
- 재고는 0 미만으로 내려가지 않도록 제한
- 주문 현황에 주문 시간, 메뉴/수량, 금액, 상태 버튼 표시
- 상태 버튼 클릭 시 `주문 접수 -> 제조 중 -> 제조 완료` 순서로 변경

## 5. 백엔드 요구사항
- 데이터 모델
  - `Menus`: 이름, 설명, 가격, 이미지, 재고 수량
  - `Options`: 옵션 이름, 옵션 가격, 메뉴 연결
  - `Orders`: 주문 시간, 메뉴/수량/옵션/금액, 상태
- 사용자 흐름
  - 메뉴 목록 조회 시 `Menus`를 기반으로 주문 화면 표시
  - 관리자 화면에서 메뉴 재고 수량 확인
  - 주문 생성 시 주문 정보를 `Orders`에 저장
  - 주문 생성 시 주문 수량만큼 메뉴 재고 차감
  - 관리자 화면 주문 상태를 `주문 접수 -> 제조 중 -> 완료`로 변경
- API 요구사항
  - 메뉴 목록 조회 API
  - 주문 생성 API
  - 주문 단건 조회 API (주문 ID 기준)
  - 주문 상태 변경 API

## 6. 현재 구현 상태
- 주문하기 화면 와이어프레임 반영 완료
- 관리자 화면 와이어프레임 반영 완료
- 백엔드(`server`) 분리 구현 완료 (Express + PostgreSQL)
- DB 스키마/시드 스크립트 및 주문/재고 API 구현 완료
- PostgreSQL(`mycafe` DB) 연결 및 초기 데이터 적용 완료
- 프런트엔드와 백엔드 API 연동 완료
  - 주문 화면: 메뉴 조회, 주문 생성
  - 관리자 화면: 재고 조회/수정, 주문 목록, 상태 변경
